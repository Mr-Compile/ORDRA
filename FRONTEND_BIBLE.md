# Ordra Frontend Bible

## Product promise
Ordra gives one local place to save, organize, scan, track and review orders from Shopee, TikTok Shop, Lazada and other stores.

## UI principles
1. Fast to understand: Home answers what is arriving, what is pending, and how much COD to prepare.
2. Offline-first: core screens never require network.
3. Review before AI save: OCR/Groq results always pass through review/correction.
4. Friendly errors: never expose stack traces or technical exception names.
5. Platform-neutral: no screen is architected only for Shopee/TikTok/Lazada.
6. Status at a glance: chips/icons, not full-card status colors.
7. Progressive disclosure: required order fields first; advanced fields optional.
8. Accessible: scalable text, semantic labels, adequate touch targets and contrast.
