# UX & Design System

> Note: superseded by `docs/uiux/DESIGN_SYSTEM.md` + the `docs/uiux/` pack (v1.1), which are
> canonical. This file is kept for reference from the original spec pack.

Brand: Ordra. Primary #5B5FEF, secondary #7C5CFC, success #35D0A0, warning #FFB547, error #F05252. Light background #F8F9FD; dark #101116.

Use Material 3 and accessible semantic colors. Status color is an accent/chip, not a full-card fill. Never rely on color alone; pair status with text/icon.

Core navigation should prioritize Home, Orders and Settings; Add Order is a prominent action. Smart Import joins the add flow once available. Keep technical errors out of user-facing copy.
