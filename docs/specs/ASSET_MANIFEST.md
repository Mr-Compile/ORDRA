# Ordra UI Asset Manifest

Required brand assets to implement/create in the Android project:
- Adaptive launcher icon: foreground/background
- Monochrome launcher icon where supported
- Ordra wordmark (optional in-app/splash use)
- Splash icon
- Optional empty-state illustrations: no orders, no search results, no upcoming deliveries, no insights

Prefer Material Symbols for functional icons: home, orders/list, add, scan/image, calendar, insights, settings, search, filter, sort, delivery/truck, payment/wallet, receipt, warranty/shield, return, refund, backup, restore, archive, edit, delete.

Do not bundle marketplace logos unless licensing/usage is intentionally handled. Platform text labels are sufficient for V1.
