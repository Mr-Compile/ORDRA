# ORDRA Accessibility

- Minimum interactive target: 48dp.
- Support Android font scaling without clipped prices/statuses/actions.
- Do not encode status using color alone; always include text/icon/semantics.
- Maintain WCAG-aware contrast using Material 3 roles.
- TalkBack labels for informative icons, images, controls, status, price, and navigation.
- Decorative icons have no redundant announcement.
- Logical focus order follows visual hierarchy.
- Forms expose labels, errors, required state, and helper text semantically.
- Animations respect reduced-motion/system animator settings where possible.
- Charts/insights require textual summaries; never rely on chart visuals alone.
