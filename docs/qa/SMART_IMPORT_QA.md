# Smart Import QA

Test clear/blurred/cropped screenshots, multiple currencies/amounts, discounts, multi-item orders, missing ETA, missing tracking, unrelated images, duplicated screenshots and unsupported platforms.

Verify OCR/AI never auto-saves, confidence is not presented as certainty, malformed AI JSON is rejected, deterministic totals are recalculated, offline behavior works, and sensitive screenshot content is not logged.
