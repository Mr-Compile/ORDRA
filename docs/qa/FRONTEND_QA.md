# Frontend QA Gate

PASS requires:
- All inventory screens implemented or explicitly deferred by phase.
- No dead navigation routes.
- Back/return behavior correct.
- Light and dark themes verified.
- Empty/loading/error/content states present where relevant.
- Add/Edit validation is friendly and preserves entered data.
- Money/date formatting consistent.
- Status chips use semantic mapping.
- Offline core screens function without network.
- Smart Import has offline fallback and review-before-save.
- Notification access is optional.
- Accessibility labels/touch targets/contrast checked.
- No raw exception text shown to users.
- No hardcoded Groq secret displayed or committed.
- No placeholder TODO screen reported as complete.
