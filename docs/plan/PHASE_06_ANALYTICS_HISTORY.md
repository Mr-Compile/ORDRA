# Phase 6 — Spending Analytics & History

## Implement
- Monthly/weekly purchase totals.
- Pending vs delivered spending.
- COD outstanding.
- Spending by platform/category.
- Purchase history with date ranges.
- Lightweight insights generated deterministically from local data.

## Scope rule
Ordra remains an order manager, not a full banking/budgeting app. Avoid financial-account connectivity in the core product.

## Exit criteria
[ ] Analytics reconcile with order totals.
[ ] Refund/cancellation rules are explicit.
[ ] Charts remain accessible and understandable without color alone.
