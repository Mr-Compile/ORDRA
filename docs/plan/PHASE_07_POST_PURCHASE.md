# Phase 7 — Post-Purchase Tools

## Implement
- Return/refund status and deadlines.
- Warranty start/end dates and reminders.
- Receipt/invoice image attachments.
- Delivery confirmation notes.
- Optional purchase rating/favorite/reorder reference.

## Exit criteria
[ ] Return/refund records do not corrupt original order history.
[ ] Warranty reminders cancel when removed/expired.
[ ] Attachments handle missing files gracefully.
