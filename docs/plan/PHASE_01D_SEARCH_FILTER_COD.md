# Phase 1D — Search, Filters, Categories & COD

## Implement
- Search product/item names, seller, tracking number (across shipments) and notes.
- Filter by platform, status, payment/COD, category and date.
- Sort newest, oldest, delivery soonest, highest total, lowest total.
- Categories/tags with sensible defaults and custom categories.
- COD summary: today, next three days and all outstanding.
- Search/filter state should be predictable and resettable.

## Exit criteria
[ ] Combined filters work correctly.
[ ] Search is case-insensitive where appropriate.
[ ] COD excludes delivered/cancelled/refunded orders.
[ ] Large order lists remain responsive.
