# Phase 0 — Product & Branding Foundation

## Goal
Freeze Ordra's identity and product boundaries before feature implementation.

## Canonical identity
- Name: Ordra
- Meaning: a coined name inspired by Order + Organize.
- Tagline: All your orders. One place.
- Platform: Android only.
- Primary: #5B5FEF
- Secondary: #7C5CFC
- Success accent: #35D0A0
- Light background: #F8F9FD
- Dark background: #101116

## Work
- Apply the name consistently in package-facing copy, docs and assets.
- Create adaptive launcher icon from the Ordra O/parcel/check concept.
- Create Android 12+ splash and legacy-compatible splash treatment.
- Implement Material 3 light/dark theme tokens.
- Define typography, spacing, radius, icon and status-chip rules.
- Keep marketplace brand colors/logos separate from Ordra identity.

## Exit criteria
[ ] No old project names remain.
[ ] Light and dark themes are documented.
[ ] Logo remains recognizable at launcher size.
[ ] Splash follows Android guidance and is fast.
[ ] Status colors are semantic and accessible.
